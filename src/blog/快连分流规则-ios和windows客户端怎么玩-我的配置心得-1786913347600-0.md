## 为啥要搞分流？道理很简单！

说白了，分流规则就是让你能聪明地决定：哪些数据流量走快连的“专属通道”去国外，哪些数据流量直接走你的本地网络访问国内。这样做的好处简直不要太多：

*   **国内应用飞快：** 比如你一边刷YouTube，一边聊微信，分流之后，微信这类国内应用就能直连，速度唰唰的，一点不带卡顿。
*   **省流量更省心：** 只有那些需要加速的国外应用才走快连通道，避免了不必要的流量消耗，也给快连服务器减轻了负担。
*   **网络更稳定：** 减少了不必要的绕路，整体网络体验当然就更顺畅，掉线、卡顿什么的都能少很多。

## 快连 iOS 客户端分流设置：手机党必备！

iOS 客户端的分流功能，对于经常在外面用手机的朋友来说，简直是神来之笔。我用下来感觉贼方便！

### 操作步骤：

1.  **打开快连APP，找到设置：** 启动快连 iOS 客户端，点屏幕右下角的“我的”小图标，然后进去选“设置”。
2.  **摸索到分流模式：** 在设置菜单里头，你会看到“分流模式”或者“分应用代理”的选项，毫不犹豫地点进去。
3.  **开始配置你的分流规则：**
    *   这里通常有“全局模式”、“直连模式”和“自定义模式”这几种。咱们肯定选“自定义模式”啊！
    *   在自定义模式下，你就能手动添加哪些应用需要走快连通道，哪些应用要走直连。这里有个小技巧，**我测试时发现**，把微信、支付宝这种国内APP设成直连后，它们的启动速度和消息接收效率简直肉眼可见地提升，完全感觉不到我在用加速服务，体验简直顺滑到爆炸。
    *   点那个“添加应用”，从列表里挑出你想分流的APP，然后选好它是“直连”还是“代理”就行了。

## 快连 Windows 客户端分流实战：PC党福利！

Windows 客户端的分流功能就更强大了，它不光能按应用分流，还能按域名来分，对于我这种爱折腾的玩家来说，简直不要太灵活！我是在**快连 Windows 客户端 v3.12.0 版本**上搞定的这些配置。

### 操作步骤：

1.  **启动快连 Windows 客户端：** 双击桌面图标或者从任务栏那里启动你的快连客户端。
2.  **进入设置界面：** 点击主界面左边的菜单图标（一般是三条横线），然后选择“设置”或者直接找“分流设置”。
3.  **开启并设置分流：**
    *   在分流设置页面，得先确保“智能分流”或者“分应用/域名代理”功能是打开的。
    *   **按应用分流：** 在“应用程序列表”里，你可以添加或删除那些需要走快连通道的程序。点“添加应用”，然后找到你的 .exe 文件选进去就OK了。
    *   **按域名分流：** 如果你要求更高，想要更精细地控制，那就在“域名列表”里加上特定域名。比如，你可以让 `*.google.com` 走代理，但 `*.baidu.com` 就走直连。是不是很酷？
    *   最后，别忘了保存你的设置并应用！

## 常见分流规则方案

*   **游戏玩家：** 把你的Steam、英雄联盟等在线游戏设置成走快连通道，这样延迟就低了，玩起来更爽。其他日常用的浏览器、聊天工具啥的，就让它们直连。
*   **视频达人：** 把Netflix、YouTube这类海外流媒体平台设成走快连，解锁地区限制，播放贼流畅。国内的爱奇艺、腾讯视频就让它们直连。
*   **程序猿/科研狗：** 把GitHub、学术资源网站等设成走快连通道，方便获取国外资料。而本地开发环境和公司内网资源，当然就直连啦。

## 常见问题（FAQ）

**Q1：我明明设置了分流，但为啥某个应用还是不给力？**
A1：首先，你得好好检查下分流规则是不是设错了。看看那个应用是不是被你放到正确的列表里了（比如，要加速的真的设成代理了吗？要直连的真的直连了吗？）。其次，有些APP可能不止依赖一个主程序，它还有些后台服务或者别的域名要访问。只设主程序可能不够用。你可以先试试把这个APP切换到全局代理模式，如果这样能正常工作，那多半就是你分流规则里漏掉了它的一些流量。

**Q2：分流规则会不会拖慢我的网速啊？**
A2：一般来说，只要分流规则设得对，它反而会提升你的整体上网体验，因为那些不需要加速的流量就不会绕快连服务器，自然延迟就低了。但如果你设错了，比如把本来该直连的APP硬是让它去走了代理，那肯定会变慢的。

**Q3：我到底应该让哪些应用走代理，哪些走直连呢？**
A3：这个很灵活，没有标准答案。我的经验是，那些你需要访问国外服务、解除地区限制，或者对延迟要求特别高的应用（比如某些游戏、VoIP通话）就应该走代理。而国内常用的APP、对速度要求不高而且没啥限制的应用（比如本地文件共享、大部分国内视频网站），就可以选择直连。建议你根据自己平时用网习惯来多试试，慢慢调到最舒服的状态。
