## 版本兼容

快连 macOS 版支持 Intel 与 Apple 芯片设备。下载时选择对应架构的安装包，避免运行兼容层带来的性能损耗。系统版本建议 macOS 11 及以上。

![快连 macOS 客户端](https://tse-mm.bing.com/th?q=%E5%BF%AB%E8%BF%9E%20macOS%20client)

## 安装与权限

将应用拖入应用程序文件夹后首次启动，系统可能要求确认网络扩展权限。在「系统设置 → 隐私与安全性」中允许快连添加 VPN 配置。若提示输入管理员密码，正常输入即可。

## 菜单栏操作

连接成功后，可在菜单栏图标快速查看状态、切换节点或断开连接。建议开启开机自启动，减少每次手动打开的操作。

## 使用建议

办公场景下优先选择稳定线路，避免频繁切换导致会话中断。定期更新客户端，获取最新节点与协议支持。
