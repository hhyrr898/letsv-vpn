## 安装前准备

在 Windows 上使用快连前，先确认系统版本与网络环境。Windows 10 与 Windows 11 均可正常运行，建议预留至少 200MB 磁盘空间。若系统防火墙较严格，安装过程中可能弹出权限提示，核对程序名称后继续即可。

![快连 Windows 安装界面](https://tse-mm.bing.com/th?q=%E5%BF%AB%E8%BF%9E%20Windows%20install)

## 安装步骤

下载快连 Windows 安装包后，双击运行。安装路径保持默认即可，除非系统盘空间不足。安装完成后，从开始菜单或桌面快捷方式启动客户端，首次打开时等待界面加载完成。

## 首次连接

打开快连后，输入账号信息并完成登录。在节点列表中选择延迟较低的线路，点击连接按钮。连接成功后，状态栏会显示当前节点名称。建议先访问常用网站，确认网络切换正常。

## 常见问题

若连接失败，检查本地网络是否正常，尝试切换其他节点。若提示权限不足，以管理员身份运行客户端。记录客户端版本号，便于后续排查。
