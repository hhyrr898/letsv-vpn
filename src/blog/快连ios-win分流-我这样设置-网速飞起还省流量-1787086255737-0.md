## 快连客户端：我的 iOS 与 Windows 分流规则配置实践

大家好啊，我是个快连老用户了，平时上班啊生活啊都离不开它。玩了一段时间，发现“分流规则”这玩意儿，搞对了能让体验质变！尤其是有iOS和Windows双端需求的朋友，怎么让它们各干各的，不浪费流量不拖慢速度，确实有讲究。今天就来跟大家唠唠我的分流配置经验，希望能帮到你！

### 分流规则是啥？为啥非得设？

说白了，分流规则就是给快连下指令：哪些流量走代理（一般是国外网站），哪些流量直接连（比如国内网站、局域网）。你要是不设，所有流量都可能绕一圈，上网肯定变慢，还会浪费流量，甚至某些国内服务都打不开。分流搞定了，就能做到国外网站嗖嗖的，国内网站也不受影响。

### iOS 客户端怎么设分流？

iOS 上的分流一般就是“智能分流”、“全局代理”或者“自定义规则”这几种。我自己呢，更喜欢弄点自定义规则。

1.  **打开快连APP，进设置：** 先确认你的iOS快连是最新版。我一般有更新就立马升，新版通常能修复bug，还提升性能。
2.  **找“分流模式”或“规则”选项：** 在快连主界面或者“设置”里，找“分流模式”、“路由规则”之类的入口，点进去。
3.  **选并改规则：**
    *   通常会有“智能分流”（推荐）、“全局代理”和“直连”。一般人，“智能分流”就够用了。
    *   要是有特定网站或App总搞不定，试试加自定义规则。点“自定义规则”或“添加规则”就行。
    *   能输域名（像 `*.example.com`）或者IP段。比如我，常把一些流媒体域名直接丢到强制代理列表里，访问起来才稳。
    *   设完了，切记保存，然后重连快连。

### Windows 客户端怎么设分流？

Windows 客户端功能比iOS丰富点，分流选项也更细。我现在用的是快连Windows客户端 3.2.1 版本，感觉分流配置用起来挺顺手的。

1.  **打开快连Windows客户端：** 双击桌面图标。
2.  **进“设置”，选“分流模式”：** 在客户端左侧或者右上角菜单里找“设置”，再点“分流模式”或“路由设置”。
3.  **搞定分流规则：**
    *   **选模式：** 一般有“智能分流”（默认推荐，自动判断国内外）、“全局代理”（全走代理）和“直连”（全不走代理）。
    *   **加自定义：** 智能分流不给力咋办？点“自定义规则”或“分流设置”旁边的“编辑”按钮。
    *   在这儿，你可以加需要代理的域名/IP，也能加需要直连的域名/IP。更高级的，还能给特定应用程序设置代理规则，比如我玩游戏时，会把游戏客户端设成直连，浏览器就留着智能分流。
    *   规则支持通配符，像 `*.google.com` 能匹配Google所有子域名。
    *   保存好规则，记得重启快连，让新规则生效。

### 我的经验和踩坑教训

搞分流规则这事儿，我可踩过一些坑，也总结点经验，分享给大家。

*   **规则优先级：** 划重点！自定义规则通常优先级最高。所以，如果某个域名没按你设的走，得看看是不是跟智能分流冲突了，或者自定义规则的顺序有没有搞对。
*   **测！测！测！** 规则设完，别以为就万事大吉了。我都会用IP查询网站或者DNS泄露测试网站测一下，看分流有没有起作用。比如访问个国内网站、再访问个国外网站，看看IP地址是不是对的。
*   **别忘了更新：** 快连客户端和规则库会时不时更新。上周我把iOS客户端升到 2.5.0 版本后，明显感觉智能分流更准了，之前得手动加的几个流媒体域名现在自己就能搞定。所以，保持最新版很重要。
*   **通配符要小心：** 用 `*.domain.com` 这种通配符的时候留个心眼，别不小心走了代理或直连了不该走的地方。

### 常见问题（FAQ）

**Q1: 规则设了没用，咋回事？**
A1: 先确认你有没有保存规则并重连快连。再看规则有没有写错，比如域名拼错了。实在不行，重启设备或快连客户端，有时候是缓存捣鬼。

**Q2: 智能分流了，为啥国内网站还是慢？**
A2: 智能分流虽说大部分国内流量能识别，但可能还是会把少数流量误判给代理了。你可以手动把这些网站加到直连规则里。另外，也检查下是不是你自己的网络环境有问题。

**Q3: 能给不同App设不同分流吗？**
A3: Windows 客户端通常可以给特定应用程序设代理或直连规则，在“自定义规则”或“分流设置”里就能找到。iOS 客户端这方面就弱一点，主要还是基于域名和IP的全局规则。
